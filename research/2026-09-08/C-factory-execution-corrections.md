## Missing or thin topics (within the report's Factory-execution scope)

1. **The `all` process role.** `resolveProcessRole` maps an unset/unknown `RECEIPT_PROCESS_ROLE` to `all`, but `deriveServerRuntimeFlags` gives HTTP only to `api` (`server/config.ts:35-47`) and `start()` in `resonate-runtime.ts:827-863` registers no Resonate function for `all`. The report's role table never says what `all` does; a docs reader running a single process will hit this first.
2. **Platform-credit model funding.** `lima-auth-byok.ts:41-70` resolves `resolveFactoryModelFunding` → `byok | platform_credit`, sets `RECEIPT_MODEL_FUNDING_SOURCE` and `RECEIPT_CODEX_MODEL_OVERRIDE`, and there is a `funding-settlement` simulation suite. The report reduces this to a parenthetical and §11 states an unqualified BYOK requirement.
3. **`RECEIPT_CONNECT_TOKEN` reuse.** `runtime/receipt-connect-env.ts:42-49` reuses an existing `process.env.RECEIPT_CONNECT_TOKEN` instead of minting a job-scoped JWT when one is present, and `RECEIPT_CONNECT_TOKEN` is in the ambient env key list (`lima-auth-env-keys.ts`). This qualifies the "job-scoped token" guarantee in §4.5 and belongs next to the `gh` caveat.
4. **Factory schedules.** `.receipt/config.json` `schedules`, `FactoryRuntimeConfig.schedules`, and `bootstrap.ts:2077` (`FACTORY_RUNTIME.schedules`) implement recurring objective creation; not mentioned.
5. **Which runtime paths are public.** The gateway exposes `/connect` (public `connect` node) and `/receipt-debug/*` (token-protected, `service-gateway.ts:1009-1021`) while the rest of the runtime is private under `/runtime`. §10/§11 should state this explicitly rather than via "prior report §1.4"; it also explains `RECEIPT_CONNECT_WORKER_GATEWAY_URL`.
6. **Computer-use sessions.** `COMPUTER_USE_SESSION_STREAM_PREFIX = "computer_use/sessions"` (`runtime-contracts.ts:23`) and the `computer-use/factory-workbench-flow.json` eval scenario are not described.
7. **Residual Lima naming.** Most credential/Codex files are `lima-*` and `lima-remote-codex-args.ts:305-308` still describes a Lima lane keeping the normal Codex sandbox, while `types.ts` says OpenSandbox is the only target. Docs writers should be told the prefix is historical.
